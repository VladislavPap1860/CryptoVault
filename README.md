# taskline

CryptoVault - десктопное приложение, предназначенное для хранения зашифрованных паролей и заметок на вашем устростве. Работа осуществяется через удобный графическй интерфейс.

Если вы желаете, чтобы ваши пароли были всегда под рукой и в безопасности, CryptoVault - это то, что вам нужно.

## Возможности

- Создание, просмотр, редактирование и удаление паролей и зметок
- Создание нескольких аккаунтов внутри программы
- Возможность загрузки в облако
- Базовый функционал доступен оффлайн

## Требования

- ОС: Windows 10/11, macOS, Linux
- Python 3.9 или выше
- Оперативная память (RAM): мин. 100 МБ
- Свободное место на диске: Менее 50 МБ

## Установка

Вариант 1. Запуск готового `.exe` (Для пользователей)

1. Перейдите в раздел [Releases](../../releases) справа на странице репозитория.
2. Скачайте последнюю версию `CryptoVault.exe`.
3. Запустите файл.

Вариант 2. Запуск из исходного кода (Для разработчиков)

1. Клонируйте репозиторий:
    ```bash
        git clone [https://github.com/VladislavPap1860/CryptoVault.git](https://github.com/VladislavPap1860/CryptoVault.git)
        cd CryptoVault

2. Создайте и активируйте виртуальное окружение:

   * Для Windows:
     ```cmd
     python -m venv venv
     venv\Scripts\activate
     ```

   * Для Linux / macOS:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

4. Установите зависимости: ```pip install -r requirements.txt```

5. Запустите приложение: ```python main.py```

## Пример использования
- Создайте ваш первый аккаунт в окне входа.
- Перейдите в раздел пароли
- Кликните на кнопку добавить пароль
- Заполните необходимые поля
- Кликнете на кнопку сохоанить пароль
- Зашифрованный файл с паролем лежит в `~/CryptoVault 1.0/your_vault.dat`.
